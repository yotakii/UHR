UHR — ملفات المشروع

1_System       : النظام كاملاً بملف واحد — افتحه بمتصفح Chrome أو Edge، يعمل بدون إنترنت.
2_NFC_Reader   : برنامج قارئ البطاقات (ACS) للابتوب + طريقة تشغيل NFC على Sunmi/الجوال (اقرأني.txt).
3_Documents    : البنية التقنية + دليل الاستخدام للفريق.
4_Source_Code  : الكود المصدري (React + TypeScript).

بناء النسخة من الكود:
  cd 4_Source_Code
  npm install
  npm run build      -> dist/index.html

حماية الرواتب (التحقق بخطوتين):
  - أي راتب أو كشف راتب أو مخالصة لا يظهر إلا بعد إدخال رمز من 6 أرقام من تطبيق
    Google Authenticator أو Microsoft Authenticator على الجوال (يعمل بدون إنترنت).
  - أول مرة لكل حساب: امسح رمز QR من النافذة، أدخل الرمز، واحفظ رموز الطوارئ الثمانية.
  - الفتح يدوم 5 دقائق ثم يُقفل تلقائياً، ويُقفل فوراً عند تسجيل الخروج أو بالضغط على زر القفل.
  - 5 محاولات خاطئة = إيقاف 60 ثانية. الرمز لا يُقبل مرتين.
  - تغيير الجوال: "غيّرت جوالك؟" ثم كلمة مرور الحساب.
  - مهم: ساعة الجوال والحاسوب يجب أن تكون على "تلقائي".
